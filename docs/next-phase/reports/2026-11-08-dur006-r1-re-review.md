## 4. Audit method and fixtures

The independent verification script was placed in `/tmp/dur006-r1-verification/r1-audit.mjs` and executed directly against `bin/matrix.mjs` as a child process.

- **Isolation:** Created fresh, isolated temporary directories (`mode 0700`) for `MATRIX_HOME`, the target workspace, and a foreign workspace.
- **Provider transport monitoring:** An HTTP loopback server intercepted all network requests. Header capture verified fake bearer values were sent during `goal start`, while a counter confirmed **zero requests** occurred during any inspect or refusal command.
- **Goal state integrity:** Before and after `goal inspect` and `goal resume` (refusal), every file in the goal storage directory (`checkpoint.json`, `journal.jsonl`, etc.) was audited for size, SHA-256 hash, permissions mode, `mtime`, and `ctime`.
- **Command execution test:** For the control case, the exact `nextCommand` emitted in JSON inspect output was executed via `bash -c` from the foreign directory to verify that shell quoting survived bash argument parsing and successfully resumed the goal.
